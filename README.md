# 花海 · ChatGPT 桌宠

用户当前需要的是 **ChatGPT Work 内置 Pets**，不是独立桌面程序。原生桌宠的动作素材、状态映射、透明精灵图与校验资料在 [`chatgpt-pet/`](chatgpt-pet/README.md)。状态由 ChatGPT 客户端触发；本仓库提供各状态的逐帧动画。制作状态以该目录的校验报告和安装记录为准。

以下是保留的早期 Electron 实验，不会自动感知 ChatGPT 的思考、等待或检查状态。

## 早期独立桌面实验

Windows Electron 透明像素桌宠。默认人物约 160 像素高，右键选择 120 / 160 / 200 三档大小。只显示角色，无场景背景、地面阴影或消息气泡。

## 使用

```powershell
npm install
npm start
```

- 左键拖动；双击切换动作与视角；右键调大小、切换视角、暂停或退出。
- 托盘右键也可操作，托盘单击重新显示。
- 透明区域点击穿透，人物区域接收操作。
- 四个参考动作：挥手、整理帽子、拉行李箱、坐着喝饮料。
- 新增右侧站立、背面背包视角。保留黑帽、黑发、橄榄绿上衣、黑裤和背包的角色设计。
- 动画是轻微呼吸位移；六张素材是独立姿势，不是逐帧行走动画。

## 素材

原始参考保留在用户的 C:\huahai。assets/sprites 为内置 ImageGen 基于参考图制作的六张透明 PNG，保留生成透明通道；新增视角有生成性补全，不是原图逐像素复制。生成提示词见 assets/ASSET_PROMPTS.md。

旧 flood-fill 脚本会误删主体，已停用并移除，避免覆盖修复的素材。

## 验证

```powershell
npm test
```

真实 Electron 渲染检查六张素材可见比例、透明角落、双击切换和三档窗口尺寸；输出截图和检查结果到 outputs/。
